# Scott-Fishing: Kayak Fishing Bite Prediction Dashboard

Interactive dashboard for predicting optimal kayak fishing times in coastal California locations. Built with consulting-level design, the app integrates free, real-time data APIs to deliver accurate bite predictions and safety information for anglers.

## Features

- **Real-Time Conditions:** Weather, tides, waves, water temperature, marine advisories
- **72-Hour Bite Score Forecast:** Hourly color-coded predictions
- **Location Selector:** Easily toggle between hotspots (Pillar Point Harbor, Pigeon Point, Pescadero, Santa Cruz)
- **Species Toggle:** Custom bite prediction for rockfish, lingcod, and salmon
- **Interactive Charts:** Tidal curves, solunar periods, weather trends, wind and wave forecasts
- **Safety Alerts:** Integrated wind and wave safety data from NOAA and NDBC
- **CSV Export:** One-click download of conditions, scores, and recommendations

## Data Sources

- Open-Meteo Marine API
- NOAA Tides & Currents API
- NOAA Weather Service API
- NOAA NDBC Buoy Data
- Solunar.org API

## How to Use

1. Open the dashboard in your browser.
2. Select a fishing location.
3. Review bite forecasts, best windows, and safety alerts.
4. Toggle fish species to view targeted predictions.
5. Use the export button to download forecast data as a CSV.

## Deployment

This app is static HTML/CSS/JavaScript and works on GitHub Pages or any modern static web host.
